## Features

- **Collapsible Sidebar** - Minimizes to icon-only mode
- **Detachable Sidebar** - Can be popped out as a floating window
- **14 Theme Options** - Including dark, light, and branded themes
- **Account Switcher** - Multi-account support with dropdown
- **Drag & Drop Navigation** - Reorderable nav items
- **Responsive Design** - Adapts to different screen sizes

## Tech Stack

- React 19
- Vite 7
- React Router DOM
- ApexCharts
- dnd-kit (drag and drop)

## Development

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
